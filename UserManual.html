AngryFM – User Manual

Version 1.0

1. Getting Started

AngryFM is a sports management game. You manage a team, set tactics, train players, and compete in a league. Java 21 or later must be installed. Launch the game from the desktop shortcut or Start Menu.

2. Main Menu

  • New Game – Start a new season.
  • Continue – Load a saved game.
  • Exit – Close the application.

3. New Game

  1. Select a sport: Football or Basketball.
  2. Select a gender category: Male or Female.
  3. Select your team from the list.

4. Dashboard

The main screen during a season. Shows current week, next match, and season record. Use the buttons on the left to navigate to Squad, Tactic, Coach, Train, Fixture, and Points Table screens.

  • Play Week – Simulate the current matchday.
  • Save & Menu – Save the game and return to Main Menu.

5. Squad

Shows your Starting Lineup and Bench. Injured players are highlighted in red and cannot start.

  • Select one player from Starting and one from Bench, then click Swap to exchange them.
  • Click Auto Set to automatically fill the lineup with the best available players.
  • Double-click a player to see their full attributes.

6. Tactics

Select a tactic from the list to apply it to your team. Tactics affect attacking and defensive performance in matches.

7. Coaches

Select a coach and click Set Active. Each coach has a specialty that provides bonuses:

  • Attacking – Boosts offensive performance.
  • Defending – Reduces opponent effectiveness.
  • Fitness – Lowers injury risk during matches.
  • General – Small bonus to both attack and defense.

8. Training

Set the intensity with the slider and click Train. Higher intensity improves player attributes more. Injured players are skipped automatically.

9. Playing a Match

Click Play Week from the Dashboard. Football is played in 2 halves; basketball in 4 quarters. A break screen appears between periods where you can make substitutions and change tactics.

  • Football: up to 5 substitutions per match.
  • Basketball: unlimited substitutions.

After the match, a summary shows the score, goal scorers or key performers, and any injuries.

10. Standings & Fixtures

  • Points Table – Full league standings with points, wins, draws, losses, and goal difference.
  • Fixture – All scheduled matches and results.

11. Save & Load

Use Save & Menu on the Dashboard to save. Save files are stored in %APPDATA%\AngryFM\saves\. To load, go to Main Menu → Continue, select your save, and click Continue. You can also delete saves from this screen.

12. End of Season

When all fixtures are played, the season ends and the champion is announced. You can start a new season with the same teams or return to the Main Menu.
